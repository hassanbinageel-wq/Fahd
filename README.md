# فهد التميمي — إدارة العملاء والتمويلات

تطبيق أندرويد (PWA + Capacitor) لإدارة العملاء والتمويلات والأقساط للمندوبين.
يعمل بالكامل بدون إنترنت ويحفظ البيانات محلياً على الجهاز.

## المميزات

### 📊 لوحة التحكم
- إجمالي المتبقي، المتأخرات، المُحصَّل، دفعات المندوب
- أقساط متأخرة، مستحقات الأسبوع، آخر العملاء
- اختصارات سريعة للإضافة والتسجيل

### 👥 العملاء
- رقم عميل دائم (لا يتغير مع أي تمويل جديد)
- بيانات العميل والكفيل
- اختيار من جهات الاتصال بالجهاز 📇
- اتصال مباشر + واتساب بضغطة
- كشف حساب موحد
- استيراد/تصدير Excel

### 💼 التمويلات
- عقد مرابحة كامل (رأس مال + ربح)
- توليد جدول الأقساط تلقائياً
- 7 حالات: 🟢 منتظم / 🟡 جزئي / 🟠 سماحية / 🔴 متأخر / ⚫ متعثر / 🔵 مكتمل
- أنواع عقود قابلة للتخصيص
- فترة سماحية قابلة للتعديل

### 💰 محرك الدفعات الذكي
- توزيع الدفعة تلقائياً على الأقساط (الأقدم أولاً)
- دفع جزئي
- دفعة أكبر من قسط واحد
- تسجيل عندما يدفع المندوب من حسابه الشخصي بالنيابة
- تتبُّع المبالغ المستحقة للمندوب
- إيصالات دفع بالكاميرا أو من الملفات

### 🧾 الفواتير
- **نسخة داخلية (المندوب)**: تُظهر كل بيانات الإيصالات وحسابات المندوب
- **نسخة العميل**: تُخفي بيانات الإيصالات الحساسة
- كشف حساب موحد للعميل
- حفظ PDF + طباعة + مشاركة

### 🗓️ التقويم والتذكيرات
- تقويم شهري بألوان حسب الحالة
- تذكيرات قبل الاستحقاق
- رسائل واتساب جاهزة

### 📈 التقارير
- تقرير المتأخرات
- دفعات المندوب المستحقة
- تحصيلات الشهر
- كشف حساب موحد لكل العملاء
- تصدير Excel لكل تقرير

### ⚙️ الإعدادات
- بيانات المندوب
- إدارة أنواع العقود
- حسابات الاستلام البنكية
- حسابات المندوب الشخصية
- قفل بكلمة مرور (SHA-256)
- نسخ احتياطي كامل JSON

## البناء

### الطريقة 1: GitHub Actions (لا تحتاج Android Studio) ⭐
1. أنشئ ريبو جديد على GitHub
2. ارفع كل ملفات المشروع
3. **مهم:** ملف `.github/workflows/build-apk.yml` قد لا يُرفع تلقائياً بسبب المجلد المخفي — أنشئه يدوياً من `Create new file` على GitHub وضع المسار `.github/workflows/build-apk.yml`
4. اذهب إلى تبويب `Actions` → شغّل `Build Android APK`
5. حمّل الملف من `Artifacts` باسم `fahd-tamimi-apk`

### الطريقة 2: محلياً
```bash
npm install
npx cap add android
node scripts/patch-android.js
npx @capacitor/assets generate --android --iconBackgroundColor '#0b3b2e' --splashBackgroundColor '#0b3b2e'
npx cap sync android
cd android
./gradlew assembleDebug
```
الـ APK النهائي: `android/app/build/outputs/apk/debug/app-debug.apk`

## المتطلبات

- Android SDK (للبناء المحلي فقط)
